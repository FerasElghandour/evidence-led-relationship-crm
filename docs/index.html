How it works

Input → Validation → Decision → Evidence

A fresh in-memory database is populated with explicitly synthetic records. Each result calls the application’s company-stage guard and qualification classifier.

Research fit can admit an inference; commercial qualification uses a stricter classification gate. A user-applied “confirmed” label does not independently verify a fact.

The Python application is a local single-user tool. This page is a recorded workflow explorer; it does not host a shared CRM or collect contact records.
